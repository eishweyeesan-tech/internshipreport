# Plan: Fix Dynamic Week Calculation for "Not Started" Internships

## Problem

When a student's `internship_start_date` is in the future (or NULL), the current code:
1. Assigns them `dynamic_week = 1`
2. Counts 0 logs for Week 1
3. Classifies them as **"Behind Schedule"** with a red badge + email alert

This is incorrect — students whose internship hasn't started yet should NOT be flagged as "behind."

## Solution: "Not Started" Badge with Full Exclusion

### Change 1: `supervisor-dashboard.php` — Dynamic Week Calculation (lines 198-225)

Add `$student_not_started` array to track students whose internship hasn't begun:

```php
$student_dynamic_week = [];
$student_not_started = [];

foreach ($all_students_detail as $sd) {
    $uid = $sd['uid'];
    $dynamic_week = 1;
    $not_started = false;

    if ($sd['internship_start_date']) {
        $start_date = new DateTime($sd['internship_start_date']);
        $end_date = $sd['internship_end_date'] ? new DateTime($sd['internship_end_date']) : null;

        if ($today_obj < $start_date) {
            $dynamic_week = 1;
            $not_started = true;  // ← NEW
        } elseif ($end_date && $today_obj > $end_date) {
            $dynamic_week = $max_week;
        } else {
            $days_elapsed = (int) $today_obj->diff($start_date)->days;
            $dynamic_week = (int) floor($days_elapsed / 7) + 1;
            $dynamic_week = max(1, min($dynamic_week, $max_week));
        }
    } else {
        $not_started = true;  // ← No start date = not started
    }

    $student_dynamic_week[$uid] = $dynamic_week;
    $student_not_started[$uid] = $not_started;
}
```

Skip not-started students from Behind/Progress/Complete counts:
