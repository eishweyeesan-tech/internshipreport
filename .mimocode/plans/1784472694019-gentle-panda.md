# Plan: Add Search Filter to Monthly Calendar

## File to modify
- `student/monthly-calendar.php`

## What to add

### 1. PHP: Capture search input (top of file, after line 48)
- Read `$_GET['holiday_search']`, trim and sanitize it
- Store as `$searchQuery`

### 2. PHP: Filter holidays by search query (after line 45)
- If `$searchQuery` is not empty, build a `$filteredHolidays` array containing only holidays where `holiday_name` contains the search string (case-insensitive via `stripos`)
- If empty, use all holidays from `$holidayMap`
- Use `$filteredHolidays` for the list display

### 3. HTML: Add search input (after the calendar grid, before the footer)
- Small search input with `🔍` icon, matching the existing sidebar style
- Submits via GET (keeps current month/year params, adds `holiday_search`)
- Shows clear button (`✕`) when there's a query

### 4. HTML: Add filtered holiday list (between search and footer)
- List of holidays matching the search query
- Each item shows: colored dot, holiday name, date
- Styled compact for sidebar width
- Max height with scroll overflow
- "No holidays found" empty state

## Approach
- Pure server-side filtering (PHP), no JavaScript needed
- GET-based so it works with the existing month navigation
- Preserves `cal_month` and `cal_year` params when searching
- Calendar grid still highlights all holidays normally — search is for the list only

## Verification
- Open `http://localhost/internreportsystem/student/monthly-calendar.php`

- Click ✕ to clear search
- Navigate months — search persists (or resets if desired)
